# BoltAI Classic (v1) is discontinued

BoltAI v1, now called BoltAI Classic, is discontinued. BoltAI v2 is a complete rewrite, with many components rebuilt in native AppKit. It fixes many bugs and issues from v1.

I’m closing the remaining v1 issues in this repository. I’m doing my best to reproduce the reported problems and verify that they no longer occur in v2, but a closed issue here does not necessarily mean it has been fixed. If you still experience a problem in v2, please report it on the [feedback board](https://feedback.boltai.com). Include your app version, macOS version, steps to reproduce it, and a link to the original GitHub issue if you have one.

## Your license

If your v1 updates period has not expired, you can [download BoltAI v2](https://boltai.com/download) and activate it with the same license key. When you activate v2, your v1 license is automatically upgraded to a corresponding v2 tier with more benefits. You don’t need to buy a separate v2 license. See the [v1 to v2 tier mapping and benefits](https://help.boltai.com/articles/9415943-license).

For licensing purposes, think of v2 as *v1.99*: it follows the same perpetual-license policy, with one year of updates and optional renewal.

If your updates period has ended, you can continue using your existing version of BoltAI Classic. You can renew the same license using the [License Manager](https://boltai.com/license-manager) and receive the usual **40% renewal discount**. Once renewed, you can activate v2 with your license key.

## Moving your data

Follow the [v1 to v2 import guide](https://help.boltai.com/articles/1796434-how-to-import-data-from-boltai-v1-to-v2). Keep Classic installed until you’ve checked that your important data appears in v2. If you include API keys in your export, keep the JSON file private and delete it after importing.

## Cloud Sync and mobile access

BoltAI v2 adds Cloud Sync and mobile access, depending on your upgraded tier and active Updates & Sync Plan. See the [v2 license guide](https://help.boltai.com/articles/9415943-license) for the details.
